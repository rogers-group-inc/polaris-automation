# polaris-automation — moved to polaris-toolbox

**This plugin is archived.** Its skill, `polaris-automation-scripts`, now lives in
[polaris-toolbox](https://github.com/rogers-group-inc/polaris-toolbox), alongside skills for

```
git clone https://github.com/rogers-group-inc/polaris-toolbox
claude --plugin-dir ./polaris-toolbox
```
